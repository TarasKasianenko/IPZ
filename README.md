# Gesture Air Hockey

Аерохокей для двох гравців, де бити керуються руками: камера → MediaPipe (`Tracker/`) → UDP → Unity (`Assets/`). Гравець може грати й сам проти комп'ютера: у лобі виберіть `Gracze: 1`.

## Що потрібно

- [Git](https://git-scm.com/)
- [Unity Hub](https://unity.com/download) і Unity **6000.6.7f1** (Hub запропонує цю версію, коли відкриєте проєкт)
- Вебкамера

Python окремо ставити не треба: на Windows перший запуск трекера сам установить `uv` і Python 3.13. На Linux потрібен `uv` або `python3`.

## Запуск

```bash
git clone https://github.com/TarasKasianenko/IPZ.git
```

1. **Запустіть трекер** і не закривайте його вікно. Перший запуск встановлює залежності та завантажує модель, тому потрібен інтернет.
   - Windows: двічі клацніть `Tracker\run.cmd`
   - Linux: `Tracker/run.sh`
2. **Відкрийте проєкт:** Unity Hub → **Add** → тека `IPZ`. Перше відкриття триває кілька хвилин.
3. **Відкрийте сцену:** у вікні Project двічі клацніть `Assets/Lobby/Lobby.unity`.
4. Натисніть **▶ Play**.

Угорі має з'явитися зелений напис `Tracker połączony`. Покажіть руку в камеру, і з'явиться курсор.

## Керування

| Дія | Рукою | Мишею |
|---|---|---|
| Навести курсор | рухати рукою | рухати мишею |
| Натиснути | звести великий і вказівний пальці | клік |
| Прогорнути меню | звести пальці й вести вгору або вниз | перетягнути або коліщатко |

У грі:

| Дія | Жест |
|---|---|
| Рухати битою | рухати відкритою долонею |
| Підтвердити готовність | показати відкриту долоню |
| Пауза, продовження | тримати кулак 1 секунду |
| Реванш після матчу | палець угору |
| Вийти в меню після матчу | тримати кулак 1 секунду |

Клавіша `Esc` у будь-який момент повертає в меню.

## Якщо не працює

- **`Cannot open camera 0`:** закрийте програми, що використовують камеру, і перевірте доступ у «Параметри → Конфіденційність і безпека → Камера». Python із Microsoft Store потребує окремого дозволу в цьому списку. Якщо камер кілька, вкажіть номер: `run.cmd --camera 1`.
- **Червоний напис `Tracker nie jest uruchomiony`:** трекер не запущено. Мишею меню працює й без нього.
- **Зламане середовище Python:** видаліть `Tracker/.venv` і запустіть трекер знову.

## Структура

| Шлях | Вміст |
|---|---|
| `Tracker/` | трекер рук на Python, деталі в `Tracker/README.md` |
| `Assets/Scripts/Tracking/` | прийом даних трекера в Unity |
| `Assets/Lobby/` | 3D-лобі: сцена, скрипти, матеріали |
| `Assets/Game/` | гра: сцена, фізика, жести, звуки |

Сцени генерують пункти меню **IPZ → Rebuild Lobby Scene** і **IPZ → Rebuild Game Scene**. Вони перезаписують ручні зміни в цих сценах.
