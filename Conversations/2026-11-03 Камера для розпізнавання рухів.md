## 4. Що зламається при переносі проєкту

- **Скрипт `ipz`** написаний на bash, тому запускати його треба з Git Bash. Він шукає `venv/bin/headroom`, а на Windows цей файл лежить у `venv\Scripts\headroom.exe`, тож шлях у скрипті доведеться поправити.
- **Headroom:**
  ```powershell
  python -m venv $HOME\.local\opt\headroom\venv
  & $HOME\.local\opt\headroom\venv\Scripts\pip install headroom-ai==0.42.0
  ```
- **Трекер камери** на Windows не відкриє камеру. У `tracker.py` камера відкривається через `cv2.CAP_V4L2`, а цей бекенд є тільки в Linux. На Windows потрібен `cv2.CAP_DSHOW` або `cv2.CAP_MSMF`. Venv трекера теж доведеться створити заново:
  ```powershell
  cd IPZ\Tracker
  python -m venv .venv
  .venv\Scripts\pip install -r requirements.txt
  .venv\Scripts\python tracker.py --show
  ```

Можу зробити, щоб `tracker.py` сам вибирав бекенд камери під систему, а `ipz` знаходив headroom і на Windows. Тоді проєкт запуститься на обох ПК без правок.
